# Fluxo Git

Edição de arquivos no escopo solicitado e inspeção de status, diff e histórico são permitidas.
Não faça staging, commit, push, merge, rebase, tag, publicação ou descarte de alterações sem pedido
explícito compatível com a operação. Não apague trabalho alheio para fazer testes passarem.

A pasta atual pode ser usada sem repositório Git inicializado. Confira antes de citar status ou diffs;
não inicialize Git ou invente histórico como parte de outra tarefa.

Quando solicitado a sugerir uma mensagem, baseie-a nas mudanças reais. Gerar texto não autoriza
executar o commit. O formato específico em [commit-message-generator.md](commit-message-generator.md)
só se aplica quando solicitado.
